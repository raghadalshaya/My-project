# Escape the Dark

A 2D shooter game developed using Unity and C#. The game features player 
movement, weapon mechanics, enemy interactions, and gameplay systems.

Git and GitHub were used for version control throughout development, 
and the final game was published as a Web build on itch.io.

## Technologies
- Unity
- C#
- Git
- GitHub
